# GeroGrain

Granular synthesis VST3/AU instrument built with JUCE.

## First prototype
- Load WAV/AIFF/FLAC/OGG source audio.
- MIDI-triggered granular playback with adjustable grain size, density, position, randomisation, pitch and stereo spread.
- JUCE parameter attachments for host automation.
- Futuristic panel artwork embedded as plugin background.
- GitHub Actions macOS build produces a downloadable VST3 ZIP.

This is an early sound-engine and UI prototype; the visual control placement and granular engine will be refined after the first listening test.
